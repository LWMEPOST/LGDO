# 知识问答测试样本集

本目录包含两类企业知识库测试材料，内容均为虚构样本，仅用于文档解析、检索增强生成、客服辅助问答、权限问答和流程问答测试。

## 目录结构

| 目录 | 场景 | 覆盖内容 |
| --- | --- | --- |
| `product_service/` | 产品知识 + 客服辅助 | PRD、FAQ、版本记录、历史工单、售后政策 |
| `admin_policies/` | 行政制度问答 | 制度文档、报销流程、采购流程、办公规范 |

## 文件格式

样本源文件以 `.md` 和 `.txt` 为主，历史工单另提供 `.csv` 与 `.jsonl`，便于测试结构化与半结构化解析。

运行生成脚本后，会在 `generated/` 目录下生成对应的 `.docx` 和 `.pdf` 文件，用于测试 Office 文档和 PDF 文档解析能力。

## 建议测试点

- 多文档召回：同一问题可能需要同时检索 PRD、FAQ 和版本记录。
- 条件规则问答：如售后政策中的时间、状态、例外条件。
- 流程类问答：如报销、采购审批节点和所需材料。
- 权限类问答：如客服、主管、管理员在工单系统中的可见范围。
- 冲突识别：历史工单与 FAQ 中的答复口径是否一致。

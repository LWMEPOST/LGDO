- 位置：`app/search.py:57`、`app/gbrain.py:198`、`app/gbrain.py:199`、`app/gbrain.py:200`、`app/gbrain.py:310`
- 问题：`ask()` 在每次请求中都会调用 `query_gbrain()`；当未配置 HTTP endpoint 时，`query_gbrain()` 会通过 `LocalMcpClient` 启动 `bun run src/cli.ts serve`，完成 MCP 初始化后再查询。这个行为在 `GBRAIN_ENABLED=true` 时会进入每一次问答的关键路径。

**问题2：编译知识库后同步全量导入 GBrain 会阻塞接口**
- 位置：`app/wiki.py:207`、`app/wiki.py:208`、`app/gbrain.py:136`、`app/gbrain.py:144`

**问题3：GBrain 查询失败会被静默降级，线上排障信息不足**
- 位置：`app/gbrain.py:198`、`app/gbrain.py:201`、`app/gbrain.py:211`、`app/gbrain.py:219`、`app/search.py:114`

**问题4：HTTP MCP 分支缺少真实请求形态测试**
